# Downora Production v1
تطبيق فعلي Flask + yt-dlp + FFmpeg.

تشغيل Docker:
1. غيّر كلمة مرور الأدمن في docker-compose.yml.
2. `docker compose up --build`
3. افتح `http://localhost:8080`
4. لوحة الإدارة: `/admin`

يدعم روابط عامة من YouTube/TikTok/Instagram/Facebook/Vimeo/X عبر yt-dlp، بدون cookies أو تسجيل دخول أو تجاوز DRM. قبل التشغيل التجاري راجع شروط كل منصة وحقوق المحتوى وسياسات الإعلانات. استخدم HTTPS وكلمة مرور قوية وحدّث yt-dlp باستمرار.
